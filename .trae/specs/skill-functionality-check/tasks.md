# 技能功能检查 - 实现计划

## [x] 任务1：验证技能系统基本功能
- **优先级**：P0
- **依赖**：None
- **描述**：
  - 检查技能系统的初始化和注册功能
  - 验证技能管理相关API的响应
  - 测试技能推荐功能
- **验收标准**：AC-1
- **测试要求**：
  - `programmatic` TR-1.1：调用 `/internal/skills` 端点应返回所有已注册的技能
  - `programmatic` TR-1.2：调用 `/internal/skills/recommend` 端点应返回基于项目状态的技能推荐
  - `programmatic` TR-1.3：验证技能工厂和技能池的基本功能
- **备注**：需要确保技能系统能正确初始化并注册所有技能

## [x] 任务2：验证分章和大纲生成功能
- **优先级**：P0
- **依赖**：任务1
- **描述**：
  - 测试大纲规划技能的执行
  - 验证生成的大纲结构是否正确
  - 检查章节信息是否完整
- **验收标准**：AC-2
- **测试要求**：
  - `programmatic` TR-2.1：执行大纲规划技能应生成包含多个章节的大纲
  - `programmatic` TR-2.2：验证每个章节都有唯一ID、标题、目标和证据要求
  - `programmatic` TR-2.3：检查大纲生成过程中的错误处理
- **备注**：需要先创建测试项目并添加需求

## [x] 任务3：验证用户参与机制
- **优先级**：P0
- **依赖**：任务2
- **描述**：
  - 测试大纲规划技能生成的问题
  - 验证问题类型和内容是否正确
  - 测试问题回答处理功能
- **验收标准**：AC-3
- **测试要求**：
  - `programmatic` TR-3.1：执行大纲规划技能应生成章节确认问题
  - `programmatic` TR-3.2：当项目有图片文件时应生成图片插入问题
  - `programmatic` TR-3.3：当项目有知识文件时应生成RAG相关问题
  - `programmatic` TR-3.4：测试 `/internal/answer-questions` 端点处理用户回答
- **备注**：需要准备包含图片和知识文件的测试项目

## [x] 任务4：验证图片插入功能
- **优先级**：P1
- **依赖**：任务3
- **描述**：
  - 测试用户选择插入图片的情况
  - 验证草稿撰写技能是否添加图片插入提示
  - 检查生成的内容是否包含图片相关信息
- **验收标准**：AC-4
- **测试要求**：
  - `programmatic` TR-4.1：设置 `enable_image_insertion` 为 true 后执行草稿撰写技能
  - `programmatic` TR-4.2：验证生成的内容包含图片插入提示
  - `programmatic` TR-4.3：验证未选择插入图片时不包含图片提示
- **备注**：需要先完成大纲确认步骤

## [x] 任务5：验证RAG信息来源功能
- **优先级**：P1
- **依赖**：任务3
- **描述**：

  - 验证草稿撰写技能是否添加知识库信息
  - 检查生成的内容是否包含RAG相关信息
- **验收标准**：AC-5
- **测试要求**：
  - `programmatic` TR-5.1：设置 `enable_rag` 为 true 后执行草稿撰写技能
  - `programmatic` TR-5.2：验证生成的内容包含知识库信息
  - `programmatic` TR-5.3：验证未选择使用RAG时不包含知识库信息
- **备注**：需要先完成大纲确认步骤

## [x] 任务6：验证技能依赖关系
- **优先级**：P1
- **依赖**：任务1
- **描述**：
  - 测试技能之间的依赖关系检查
  - 验证在依赖未满足时是否返回错误
  - 检查依赖满足时是否正常执行
- **验收标准**：AC-6
- **测试要求**：
  - `programmatic` TR-6.1：尝试在未完成需求解析的情况下执行大纲规划技能
  - `programmatic` TR-6.2：尝试在未完成大纲规划的情况下执行草稿撰写技能
  - `programmatic` TR-6.3：验证依赖满足时技能能正常执行
- **备注**：需要测试各种依赖场景
