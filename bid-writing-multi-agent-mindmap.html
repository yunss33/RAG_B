多智能体 + 深度思考 + RAG 标书系统

标书写作项目核心智能体思维导图

目标不是做一个“单模型写文案”，而是做一个面向标书生产的协作系统：由调度层拆解任务，RAG 提供企业知识与历史样板，深度思考层负责理解招标文件与写作策略，执行层负责撰写、校验、补证、评分与成稿。下面这张图给的是第一版最重要的智能体分工。

核心中枢：任务编排与状态管理 知识底座：RAG 检索、证据绑定、版本控制 执行层：理解、规划、写作、评审、整合 约束：当前版本不联网，全部知识来自本地 RAG

1. 指挥与拆解层

决定“先做什么、谁来做、做到什么算完成”，是整个系统的调度中枢。

总控编排智能体

最核心，类似 Manus 的任务总导演

  • 接收用户任务、项目配置、标书目标
  • 维护任务树、Agent 状态、交付里程碑
  • 决定串行/并行执行与重试策略

招标文件解析智能体

把招标书拆成可执行要求

  • 抽取资格项、评分项、废标项、交付格式
  • 识别技术、商务、价格、资质等章节要求
  • 输出结构化 requirement schema

写作策略规划智能体

深度思考主力，负责写作路线

  • 决定章节顺序、证据使用优先级、差异化卖点
  • 识别哪些内容必须引用 RAG 证据
  • 给后续写作 Agent 下发章级写作 brief

2. 知识与证据层

不联网时，这一层决定系统是不是“会写且写得准”。

RAG 检索智能体

面向查询，负责召回

  • 从企业资质、案例库、产品资料、制度文档中召回片段
  • 支持按章节、主题、评分点定向检索
  • 返回证据片段、来源、版本号、置信度

知识路由智能体

决定去哪个知识库找什么

  • 识别请求属于资质、案例、技术方案、实施组织还是售后
  • 把查询路由到对应索引或知识域
  • 减少无关召回和上下文污染

证据绑定智能体

负责“这句话的依据是什么”

  • 将写作段落绑定到具体 RAG 证据
  • 标记缺证内容、弱证内容、冲突证据
  • 为审核 Agent 提供可追溯引用链

图片资产检索智能体

负责图从哪里来、是否可用

  • 从本地 RAG 图片库、项目素材库、历史标书附件中检索图片
  • 按产品图、架构图、资质扫描件、案例现场图等类型筛选
  • 返回图片路径、来源、用途标签和清晰度信息

核心系统目标

做一个面向“标书生成”的多智能体系统，而不是通用 Agent。系统主线应围绕 解析需求 → 检索证据 → 制定策略 → 分章写作 → 多轮评审 → 成稿装配 展开。

输入：招标文件、企业知识库、历史标书、产品资料、项目约束
推理：深度思考用于 requirement 拆解、评分导向规划、章节策略与冲突消解
知识：当前阶段全部走 RAG，不联网，强调可追溯、可审计、可版本化
输出：结构化大纲、章节草稿、证据引用、审查报告、最终 HTML/Word/PDF 成稿

3. 写作与整合层

把 requirement 和知识真正转成高质量章节内容。

章节写作智能体

按章节并行生产正文

  • 依据章级 brief、风格规范和证据集生成内容
  • 区分技术方案、商务响应、实施计划、售后服务等模板
  • 输出结构化草稿与待补充项

措辞优化智能体

负责专业表达和中标语气

  • 统一术语、口径、格式和语气
  • 增强响应性、针对性和专业度
  • 避免空话、套话、无依据夸大

插图决策智能体

负责哪里该放图、放什么图、由谁确认

  • 根据章节内容判断是否需要产品图、流程图、架构图、资质图或案例图
  • 给用户提供候选图片和插入位置，而不是直接自动落图
  • 输出图片插入建议单，供装配 Agent 执行

成稿装配智能体

负责章节拼装与交付

  • 将章节合并为最终目录结构
  • 处理封面、目录、章节编号、附录清单
  • 按用户选定结果插入图片、图题、编号和引用说明
  • 导出 HTML 基稿，后续可扩到 DOCX/PDF

4. 审核与闭环层

这一层直接决定成品能不能投、会不会废标、分数会不会低。

合规审查智能体

先查不能错的红线

  • 检查资格条件、格式要求、硬性响应、废标项
  • 识别缺材料、漏响应、表述冲突
  • 输出风险清单与整改建议

评分模拟智能体

模拟评标专家视角

  • 按评分表评估每章节得分潜力
  • 指出薄弱项与可加分项
  • 反向驱动再次检索和重写

一致性校对智能体

负责全书前后不打架

  • 检查公司名、项目名、参数、工期、人员配置等一致性
  • 识别重复段落、互相矛盾、引用失配
  • 给装配 Agent 返回修订指令

建议第一期必须有的 Agent

  • 总控编排智能体
  • 招标文件解析智能体
  • 写作策略规划智能体
  • RAG 检索智能体
  • 证据绑定智能体
  • 章节写作智能体
  • 合规审查智能体
  • 一致性校对智能体
  • 成稿装配智能体

建议第二期再加的 Agent

  • 资质材料补全智能体：自动识别缺失附件和证明材料
  • 案例匹配智能体：按行业、规模、能力标签自动挑选类似项目
  • 价格响应智能体：报价说明、成本边界、风险提示
  • 复盘学习智能体：把中标/废标结果回灌到知识库和策略层
  • 人机协作审稿智能体：支持人工批注后再迭代重写

图片插入建议的用户选择项

  • 插图模式：不插图 / 仅关键章节 / 全文按需建议
  • 图片来源：仅本项目素材 / 企业知识库 / 历史标书图库
  • 图片类型：产品图 / 架构图 / 流程图 / 资质扫描件 / 案例现场图
  • 插入方式：用户逐张确认 / 按章节批量确认 / 使用默认策略自动通过
  • 版式要求：大图整行 / 图文左右排 / 小图并排 / 附录集中展示

图片能力的最小闭环

  • 先让图片资产检索智能体从本地资料库召回候选图
  • 再由插图决策智能体生成“章节-图片-位置-用途”候选清单
  • 最后给用户一个选择界面，确认后由成稿装配智能体落到 HTML
  • 这样能避免图片乱插、错插、重复插，也方便后续扩展到 Word 导出
